# RobotFace — робот с живым лицом и веб-пультом

Проект интерактивного робота с процедурно генерируемым «живым» лицом на экране, веб-интерфейсом для управления и связью с внешним контроллером моторов и сервоприводов.

## 📸 Что это?
Робот умеет:
*   Отображать 16 эмоций, анимации, моргать и «дышать» на TFT-экране.
*   Принимать команды через Wi-Fi (веб-пульт `http://192.168.4.1` или IP в локальной сети).
*   Общаться через чат (офлайн-заготовки или нейросеть Ollama/OpenAI).
*   Управлять моторами ног и сервоприводами через внешний контроллер (Arduino Mega).
*   Получать обратную связь о текущем состоянии.

## 🧩 Архитектура (Текущая)
Проект разделён на **3 вычислительных узла**, так как ESP8266 не хватает оперативной памяти для одновременной отрисовки спрайтов, Wi-Fi и веб-сервера.

1.  **Плата А (Main) — ESP8266 (NodeMCU / Wemos D1 mini)**
    *   **Задачи:** Wi-Fi, веб-сервер, «мозг» (чат, Ollama), хранение настроек в LittleFS.
    *   **Связь:** ESP-NOW (отправка команд и приём статуса от Платы Б).
2.  **Плата Б (Face) — ESP8266 (NodeMCU / Wemos D1 mini)**
    *   **Задачи:** Отрисовка лица на TFT-экране (ST7735S 80x160), обработка анимаций и эмоций, управление драйвером моторов.
    *   **Связь:** ESP-NOW (приём команд от Платы А), UART (SoftwareSerial с Arduino Mega).
3.  **Плата В (Motors) — Arduino Mega 2560**
    *   **Задачи:** Непосредственное управление драйвером моторов (DRV8833) для колёс/ног и **4 сервоприводами MG996R** (два для бёдер, два для колен).
    *   **Связь:** UART (аппаратный Serial3 с Платой Б).

## 📂 Структура кода (Основные модули)
*   **`main.cpp`:** Инициализация, главный цикл, обработка ESP-NOW, настройки.
*   **`webui.cpp`:** Веб-интерфейс (HTML/CSS/JS), API-эндпоинты (`/api/status`, `/api/emotion`, `/api/drive` и т.д.).
*   **`brain.cpp`:** Логика «мозга» (парсинг эмоций из ответов нейросети, офлайн-ответы).
*   **`face.cpp`:** Движок отрисовки лица (спрайты, морфинг эмоций, анимации).
*   **`motors.cpp`:** Отправка команд на Arduino Mega по UART.

## 🛠 Схема соединения

### Плата Б (Face) — Дисплей ST7735S (SPI)
Пины взяты из `platformio.ini` и не конфликтуют с другими модулями.
*   **ESP8266 D7 (GPIO13)** ---> **SDA (MOSI)**
*   **ESP8266 D5 (GPIO14)** ---> **SCL (SCLK)**
*   **ESP8266 D1 (GPIO5)**  ---> **CS**
*   **ESP8266 D2 (GPIO4)**  ---> **DC**
*   **ESP8266 D3 (GPIO0)**  ---> **RST** *(или D4, если D3 занят)*
*   **ESP8266 3.3V**        ---> **BLK (Подсветка)**
*   **ESP8266 GND**         ---> **GND**

> *Примечание: В `platformio.ini` указан `TFT_CS=5`, `TFT_DC=2`, `TFT_RST=4`. Это пины D1, D2, D4 соответственно.*

### Связь Платы Б и Arduino Mega (UART)
*   **ESP8266 D8 (GPIO15)** ---> **Mega пин 15 (RX3)** (Команды от ESP к Mega)
*   **ESP8266 D6 (GPIO12)** <--- **Mega пин 14 (TX3)** (Ответы от Mega к ESP, через делитель напряжения 10К/10К)
*   **ESP8266 GND** --- **Mega GND** (Общая земля)

### Arduino Mega — Драйвер моторов DRV8833
*   **Mega пин 5 (PWM)** ---> **AIN1** (Левый мотор)
*   **Mega пин 6 (PWM)** ---> **AIN2** (Левый мотор)
*   **Mega пин 9 (PWM)** ---> **BIN1** (Правый мотор)
*   **Mega пин 10 (PWM)** ---> **BIN2** (Правый мотор)
*   **Mega пин 4** ---> **STBY** (Включение драйвера)
*   **Mega GND** --- **DRV8833 GND**

### Arduino Mega — Сервоприводы MG996R (4 шт.)
*   **Сервопривод 1 (Левое бедро)** ---> **Mega пин 44** (PWM)
*   **Сервопривод 2 (Правое бедро)** ---> **Mega пин 45** (PWM)
*   **Сервопривод 3 (Левое колено)** ---> **Mega пин 46** (PWM)
*   **Сервопривод 4 (Правое колено)** ---> **Mega пин 47** (PWM)
*   **Питание сервоприводов** ---> Отдельный источник 5-6В (не от Mega, чтобы не было просадок!)
*   **GND сервоприводов** ---> Общая земля с Mega.

## 🎭 Библиотека эмоций и код отрисовки

Все эмоции прописаны в `face.cpp` в функции `applyPreset(int idx, FaceParams &p)`. Каждая эмоция задаёт параметры для глаз, бровей, рта и спецэффектов.

### Список эмоций (16 шт.)
1.  **neutral** (Нейтраль) — базовое состояние.
2.  **happy** (Радость) — прищуренные глаза, улыбка, румянец.
3.  **sad** (Грусть) — опущенные брови, слеза, уголки рта вниз.
4.  **angry** (Злость) — наклонённые брови, красные глаза, рот сжат.
5.  **surprised** (Удивление) — широко открытые глаза, рот буквой «О».
6.  **sleepy** (Сонливость) — полузакрытые глаза, «Zzz» над головой.
7.  **thinking** (Задума) — одна бровь приподнята, рот сжат.
8.  **love** (Любовь) — глаза-сердечки, румянец, улыбка.
9.  **fear** (Испуг) — широкие глаза, дрожь, рот открыт.
10. **shy** (Смущение) — взгляд вниз, румянец, улыбка.
11. **wink** (Подмиг) — один глаз закрыт, улыбка.
12. **cool** (Крутой) — солнечные очки, ухмылка.
13. **dizzy** (Дурно) — спирали в глазах, волнистый рот.
14. **dead** (Отключён) — крестики вместо глаз, рот открыт.
15. **suspicious** (Подозрение) — один глаз прищурен, бровь поднята.
16. **excited** (Восторг) — звёзды в глазах, широкий рот, румянец.

### Пример кода отрисовки (из `face.cpp`)
```cpp
static void applyPreset(int idx, FaceParams &p) {
  p = makeBase();
  switch (idx) {
    case 1:  // happy
      p.eye_h = 13; p.eye_w = 19; p.brow_dy = -2;
      p.mouth_curve = 0.8f; p.mouth_w = 18; p.blush = true;
      p.eye_color = rgb565(255, 238, 190);
      break;
    case 2:  // sad
      p.eye_h = 20; p.open = 0.8f; p.tilt = 8; p.brow_angle = 18;
      p.brow_dy = -1; p.mouth_curve = -0.6f; p.mouth_w = 15;
      p.tear = true; p.eye_color = rgb565(190, 205, 235);
      break;
    // ... и так далее для всех 16 эмоций
  }
}

## 🚀 Планы на будущее
*   **Аппаратная замена:** Переход с ESP8266 на **ESP32-S3** (с PSRAM). Это объединит функции Плат А и Б на одной плате, так как ESP32-S3 имеет достаточно памяти для одновременной работы веб-сервера, спрайтов и Wi-Fi.
*   **Аудио:** Подключение динамика и реализация TTS (Text-to-Speech) через SD-карту.
*   **Нейросети:** Возможный запуск лёгких моделей (TTS) прямо на ESP32-S3.
